translated program actually compiles or behaves correctly \cite{bleu_metric,
tran2019ruby}. CodeBLEU improves this by incorporating syntax and data-flow
information, but it still cannot directly measure functional correctness
\cite{ren2020codebleu}. As a result, execution-based evaluation methods, which
compile and test generated programs, are increasingly used because they provide
a more realistic assessment of code quality \cite{huang2022exeds,
evtikhiev2022bleu}.

Fine-tuning is commonly used to adapt pre-trained models to specific code
translation tasks, but its effectiveness depends on factors such as the model
architecture, the language pair, and the quality of the training dataset.
Previous studies often evaluate only base models, rely on prompting without 
additional training, or use only similarity-based metrics such as BLEU and
CodeBLEU \cite{aljagthami2025prompt, yang2024llm}. Recent work has shown that
fine-tuning can improve performance, especially when models are trained on
task-specific datasets and evaluated using execution-based methods rather than
only token-level similarity metrics \cite{peft_code}. Therefore,
systematic comparison between base and fine-tuned models remains necessary,
particularly when both similarity-based and execution-based evaluation methods
are used.

This thesis focuses on the comparative evaluation of code translation models. It
investigates how fine-tuning affects model performance, and compares different
models using both similarity-based metrics (BLEU \cite{bleu_metric}) and execution-based evaluation
method (CodeEditorBench \cite{codeeditorbench}).
The thesis also examines how these evaluation
methods relate to each other, particularly whether improvements in textual
similarity correspond to improvements in functional correctness. CodeEditorBench
was selected because it evaluates translated code through compilation and test
execution, providing a more realistic assessment than token-level similarity
metrics alone.
