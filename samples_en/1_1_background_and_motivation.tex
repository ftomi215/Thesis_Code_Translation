\section{Background and Motivation}

Modern software systems are becoming increasingly complex, often consisting of multiple components written in different programming languages. This diversity is driven by the need to leverage the strengths of various technologies, frameworks, and ecosystems. As a consequence, developers frequently face the challenge of translating or migrating code between programming languages to ensure maintainability, scalability, and long-term sustainability of software systems.

One of the main motivations behind code translation is the modernization of legacy systems. Many organizations still rely on outdated programming languages, which are difficult to maintain and integrate with modern technologies. Translating such systems into newer languages can significantly reduce technical debt and improve system performance. Additionally, code translation enables cross-platform development and reuse of existing solutions, reducing development time and cost. This problem has gained increasing importance due to the growing demand for multi-language software development \cite{code_translation_survey}.

Traditionally, code translation has been performed manually or through rule-based tools. These approaches rely on handcrafted mappings between programming languages, which are often difficult to generalize and maintain. As software systems grow in size and complexity, these methods become less practical. In recent years, deep learning-based approaches have emerged as a promising alternative. These methods treat code translation similarly to natural language translation, allowing models to learn patterns directly from large-scale datasets \cite{code_translation_survey}.

The introduction of transformer-based architectures has significantly advanced the field. Modern models are capable of capturing both syntactic and semantic relationships in code, enabling more accurate translations. These models are typically trained on large corpora of source code and leverage transfer learning to adapt to specific tasks. As a result, they can generalize across different programming languages and even handle previously unseen scenarios.

Despite these advancements, automatic code translation remains a challenging task. Unlike natural language, programming languages require strict syntactic correctness and precise semantic preservation. Even small errors can lead to compilation failures or incorrect program behavior. Furthermore, differences in programming paradigms, libraries, and runtime environments introduce additional complexity. Studies have shown that current large language models still struggle to reliably generate correct translations, especially for complex or large-scale codebases \cite{llm_limitations}.

Another important challenge is evaluation. Traditional metrics, such as token-level similarity, do not adequately capture the functional correctness of translated code. As a result, recent research has shifted towards execution-based evaluation methods, where translated programs are tested using predefined test cases. These approaches provide a more realistic assessment of model performance but also highlight the limitations of current techniques.

All in all, the rapid development of deep learning and large language models has created new opportunities for automating code translation. However, significant challenges remain, particularly in ensuring correctness, scalability, and robustness. These challenges motivate further research in this area and form the foundation of this thesis.
