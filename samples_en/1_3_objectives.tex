\section{Objectives and Research Questions}

The main objective of this thesis is to investigate the effectiveness of deep
learning-based approaches for automatic source code translation, with a
particular focus on the effect of fine-tuning and the reliability of different
evaluation methods. Although modern large language models already perform well
on many code-related tasks, existing research provides limited
insight into how fine-tuning affects translation quality, partly
due to the limitations of current evaluation metrics, which often
fail to capture functional correctness \cite{codescore2023, tran2019ruby}.


To address this problem, the thesis compares base and fine-tuned versions of
multiple code-oriented language models under the same experimental conditions
on a code translation task. The comparison focuses on translation quality in
terms of execution-based correctness and similarity-based metrics. The models are fine-tuned on the Java-to-C++ portion of the XLCoST dataset \cite{xlcost} and evaluated on the
CodeEditorBench benchmark \cite{codeeditorbench} using consistent preprocessing,
prompting, and evaluation procedures. This setup enables a controlled comparison
of different model architectures and allows the impact of fine-tuning on code
translation performance to be quantified across multiple evaluation dimensions
in a fair and reproducible way.

A further objective is to investigate the relationship between similarity-based
metrics and execution-based evaluation methods. Previous studies have shown that
metrics such as BLEU often correlate poorly with functional correctness,
motivating the use of execution-based evaluation \cite{evaluation_limitations,
huang2022exeds}.  In this thesis, this relationship is examined by computing both
similarity-based scores and execution-based results (based on test case
execution) for each translated program and analyzing their correlation.

Based on these objectives, the thesis is guided by the following research
questions:

\begin{itemize}
    \item \textbf{RQ1: How effective are current large language models in source code translation between programming languages?}

    \item \textbf{RQ2: To what extent does fine-tuning improve the code translation performance of these models in terms of syntactic and functional correctness?}

    \item \textbf{RQ3: How well do traditional similarity-based metrics (e.g., BLEU) reflect the functional correctness of translated code, and how do they relate to execution-based evaluation methods?}

    \item \textbf{RQ4: What types of errors are most commonly produced by large language models during code translation?}
\end{itemize}
