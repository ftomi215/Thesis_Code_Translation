\section{Execution-Based Results}

Execution-based evaluation was performed using CodeEditorBench, where the
generated C++ translations were compiled and executed against predefined test
cases. Compared to BLEU score, this evaluation provides a more direct measure of
functional correctness because it captures whether the translated program
compiles and produces the expected outputs.

\subsection{Accepted Solutions and Compilation Errors}


Table~\ref{tab:execution_results} presents the number of accepted solutions and
the distribution of major error categories for each evaluated model.

For StarCoder2, the number of accepted solutions increased from 55 for the base
model to 133 for the fine-tuned model. The number of compilation errors
decreased from 390 to 287, while the number of wrong answers increased from 57
to 75. Runtime errors also increased from 4 to 13.

For Qwen2.5-Coder-3B-Instruct, the number of accepted solutions increased from
101 for the base model to 168 for the fine-tuned model. Compilation errors
decreased from 324 to 219. At the same time, the number of wrong answers
increased from 63 to 96, while runtime errors decreased from 15 to 9.

\subsection{Additional Error Types}
Table~\ref{tab:error_types} shows additional, less frequent error categories
observed during execution.

Presentation errors, time limit exceeded errors, and output limit exceeded
errors occurred less frequently across all models. For StarCoder2, presentation
errors decreased from 2 to 0 after fine-tuning, while time limit exceeded errors
remained unchanged at 2. No output limit exceeded errors were observed.

For Qwen2.5-Coder-3B-Instruct, presentation errors increased from 3 to 10, while
time limit exceeded errors increased from 4 to 5. Output limit exceeded errors
appeared only in the fine-tuned model, with a total of 3 cases.
