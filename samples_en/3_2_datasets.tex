\section{Dataset}

Two different datasets are used in this work: one dataset for model training
and a separate dataset for evaluation.

\subsection{Training Dataset}

The fine-tuned models are trained using the XLCoST dataset.
XLCoST is a large-scale benchmark designed for cross-lingual code intelligence tasks,
including code translation, code summarization, and code search
\cite{zhu2022xlcost}.

XLCoST contains parallel code snippets in seven programming languages:
C++, Java, Python, C\#, JavaScript, PHP, and C. In addition, the dataset also
includes aligned English descriptions. The dataset provides both snippet-level
and program-level parallel examples, making it suitable for supervised code
translation tasks. Given a code sample in one language, the dataset often
contains the same implementation in several other programming languages
\cite{zhu2022xlcost}. :contentReference[oaicite:0]{index=0}

For this thesis, only the code translation portion of XLCoST is used,
specifically the Java-to-C++ translation pairs. For training, the original
dataset splits are loaded and filtered to retain only Java source code and the
corresponding C++ target code. These code pairs are then formatted into
instruction-style prompts and used for supervised fine-tuning.

\subsection{Evaluation Dataset}

A separate evaluation dataset is used to assess model performance after
training. Although XLCoST provides predefined train, validation, and test
splits, it is not used for the final evaluation in this thesis because XLCoST
does not include executable test cases or expected runtime outputs. As a result,
it is suitable for similarity-based evaluation using BLEU or CodeBLEU, but it
does not support execution-based evaluation of functional correctness.
Therefore, XLCoST is used only for fine-tuning, while the final evaluation is
performed on CodeEditorBench \cite{codeeditorbench}.

CodeEditorBench is a benchmark designed to evaluate code editing capabilities of
large language models in realistic software engineering scenarios. It includes
tasks such as debugging, code polishing, requirement switching, and code
translation, covering diverse programming tasks and complexity levels
\cite{codeeditorbench}. :contentReference[oaicite:1]{index=1}

For the purposes of this thesis, only the code translation subset of
CodeEditorBench is used. The models receive Java input code and are required to
generate the corresponding C++ translation. The generated output is then
compiled and tested using the execution framework provided by CodeEditorBench.

In addition to execution-based evaluation, BLEU score is also computed for the
generated translations. This makes it possible to compare similarity-based and
execution-based evaluation methods on the same set of examples.
